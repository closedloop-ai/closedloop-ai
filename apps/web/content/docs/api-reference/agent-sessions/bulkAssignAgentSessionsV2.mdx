          Accepts an API key with `write` scope, or a signed-in Closedloop
          session. Still ALL-OR-NOTHING, exactly like `POST
          /agent-sessions/bulk-assign`: a set containing an id that is absent or
          outside the caller's organization writes NOTHING. What changes is the
          reporting — instead of a bare 404, the response names the offending
          ids `artifacts_not_found` (404) and every other id `batch_refused`
          (424), so a client can say which id cost the batch. Returns 200 with
          one result per DISTINCT requested id, in the order the caller first
          named it, even when some items fail. Read each item's own `status` and
          `code`; treat an unrecognized `code` as a generic failure for that
          item.
