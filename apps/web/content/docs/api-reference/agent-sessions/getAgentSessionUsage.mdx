      - content: >-
          Aggregates the organization's agent sessions into a usage summary:
          session and token totals, the three-way cost split
          (subscription-covered, confirmed metered, and unclassified spend), and
          breakdowns by user, model, harness, and repository. Accepts the same
          filters as `GET /agent-sessions` and covers exactly the population
          that endpoint lists for the same query, so the totals reconcile
          against the list. Like the list, the date window is an ACTIVITY window
          on `lastActivityAt`. Pass `comparison=prior` to also receive
          server-computed period-over-period movement. Requires the `read`
          scope.
