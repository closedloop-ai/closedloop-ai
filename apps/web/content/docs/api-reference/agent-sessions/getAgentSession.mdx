          Returns one agent session with its detail-only extensions — per-model
          token usage, the session's agents, its raw event stream, and per-file
          transcript availability — on top of every field the list row carries.
          The read is scoped to the authenticated organization, so a session
          belonging to another organization returns `404` rather than `403`.
          Requires the `read` scope.
