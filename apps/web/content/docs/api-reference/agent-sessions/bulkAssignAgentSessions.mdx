      - content: >-
          Assigns one field — `project` or `owner` — across a set of sessions.
          ALL-OR-NOTHING: every ID is authorized individually against the
          caller's organization and the written row count is compared against
          the requested ID count inside a transaction, so a set containing an ID
          that is absent or outside the organization is refused whole with `404`
          and nothing is written. `assignedCount` therefore always equals the
          number of distinct IDs sent and can never report a partial
          application. Requires the `write` scope.
