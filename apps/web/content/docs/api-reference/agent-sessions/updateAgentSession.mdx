      - content: >-
          Updates the name, lifecycle status, project, or owner of one session
          in the caller's organization. `projectId` and `ownerUserId` are
          tri-state — omit to leave alone, `null` to clear, a UUID to assign. A
          session in another organization returns `404` rather than `403`. Note
          that `status` is rewritten by the desktop sync's update arm on the
          next sync of the same run; `name` is not, because a rename is stored
          apart from the collector-derived name. Renaming additionally requires
          that the caller OWN the session or hold an admin role in the
          organization — any other member gets `403` — and must be sent on its
          own, since a body pairing `name` with `status`, `projectId`, or
          `ownerUserId` is rejected with `400` rather than half-applied.
          Requires the `write` scope.
