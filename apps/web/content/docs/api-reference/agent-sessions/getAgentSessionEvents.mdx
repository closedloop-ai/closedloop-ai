      - content: >-
          Returns one keyset page of the session's raw event stream, oldest
          first, in the same `(createdAt, externalEventId)` order as the
          `events` prefix on `GET /agent-sessions/{id}`. That prefix stops at
          the detail read's row ceiling (`eventsTruncated`); this endpoint is
          how a client reaches the events past it, one page at a time. Replay
          `nextCursor` verbatim as the next request's `cursor` — its absence
          means the page you hold is the last one. The read is scoped to the
          authenticated organization, so a session belonging to another
          organization returns `404` rather than `403`. Requires the `read`
          scope.
