      - content: >-
          Returns how many agent sessions each DISPLAYED status holds for one
          filter set, in a single request that builds no per-session projection.
          Accepts the same filters as `GET /agent-sessions` EXCEPT `status` and
          `statuses`, which are REJECTED with a 400 rather than accepted and
          ignored: this endpoint answers for every status at once, so a status
          selection would zero every bucket the caller did not name. It also
          takes no `limit`, `offset`, `sortBy`, `sortDir` or `sorts` - there are
          no rows to page or order, and on the list `limit` bounds the rows
          returned rather than the work done to build them. Like the list, the
          date window is an ACTIVITY window on `lastActivityAt`, and the counts
          cover the population `GET /agent-sessions` lists for the same query -
          with one bounded exception under a cost-bucket filter, described on
          `total`. Requires the `read` scope.
