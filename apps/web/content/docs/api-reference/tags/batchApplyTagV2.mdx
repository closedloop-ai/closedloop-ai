      - content: >-
          Accepts an API key with `write` scope, or a signed-in Closedloop
          session. The per-item sibling of the v1 batch tag apply, which refuses
          the whole batch when any id is missing from the organization. This
          tags the ids that resolved and reports the rest `artifacts_not_found`.
          A `tagId` outside the caller's organization fails every item
          identically, so it stays a 404 envelope. Returns 200 with one result
          per DISTINCT requested id, in the order the caller first named it,
          even when some items fail. Read each item's own `status` and `code`;
          treat an unrecognized `code` as a generic failure for that item.
