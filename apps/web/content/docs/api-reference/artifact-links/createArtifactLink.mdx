      - content: >-
          Requires an API key with `write` scope. Creates a directional link
          between two artifacts. Use this to establish relationships such as: a
          PRD PRODUCES an IMPLEMENTATION_PLAN (`sourceId=prd, targetId=plan,
          linkType=PRODUCES`), a blocking dependency between two plans
          (`linkType=BLOCKS`), or a general association (`linkType=RELATES_TO`).
          The `sourceId` and `targetId` accept UUIDs or slugs of any artifact
          type (documents, branches, etc.). Duplicate (sourceId, targetId,
          linkType) tuples are rejected.
