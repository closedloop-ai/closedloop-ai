      - content: >-
          Returns links associated with the specified artifact. Links represent
          directional relationships between artifacts: **PRODUCES** means the
          source artifact generated or produced the target (e.g., a PRD PRODUCES
          an IMPLEMENTATION_PLAN), **BLOCKS** means the source is blocking
          progress on the target, **RELATES_TO** is a general non-hierarchical
          association. Use `direction` to control which end of the link the
          query artifact appears on: `source` returns links where the artifact
          is the source, `target` returns links where it is the target, `both`
          (default) returns all links regardless of direction. Use `mode=tree`
          with `maxDepth` to traverse multi-level dependency chains (e.g., PRD →
          PLAN → FEATUREs).
