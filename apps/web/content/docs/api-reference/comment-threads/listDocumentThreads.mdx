          Returns all comment threads attached to the specified document. Each
          thread contains one or more comments. Threads have a `status` of OPEN
          (active discussion) or RESOLVED (closed discussion). Use
          `?status=OPEN` to fetch only active threads, or `?status=RESOLVED` to
          fetch closed ones. Omit `status` to get all threads regardless of
          state.
