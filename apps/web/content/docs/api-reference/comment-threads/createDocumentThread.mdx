      - content: >-
          Creates a new comment thread on the specified document. When
          `anchorText` is provided, the thread is anchored to a specific piece
          of document text. When `anchorText` is omitted, the thread is created
          as an unanchored artifact-level document comment. The first comment is
          provided as `body`. The thread will have OPEN status until explicitly
          resolved.
