      - content: >-
          Accepts an API key with `write` scope, or a signed-in Closedloop
          session. The per-item sibling of the v1 batch priority write, which
          refuses the whole batch when any id is missing or any guarded row
          moved under it. This commits the eligible documents and reports the
          rest item by item. Returns 200 with one result per DISTINCT requested
          id, in the order the caller first named it, even when some items fail.
          Read each item's own `status` and `code`; treat an unrecognized `code`
          as a generic failure for that item.
