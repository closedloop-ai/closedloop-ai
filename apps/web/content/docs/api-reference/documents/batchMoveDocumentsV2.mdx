      - content: >-
          Accepts an API key with `write` scope, or a signed-in Closedloop
          session, as its v1 sibling does. The per-item sibling of the v1 batch
          move, which refuses the whole batch when any id is missing. This moves
          the documents it found and reports the rest `artifacts_not_found`. A
          `targetProjectId` outside the caller's organization fails every item
          identically, so it stays a 400 envelope. Returns 200 with one result
          per DISTINCT requested id, in the order the caller first named it,
          even when some items fail. Read each item's own `status` and `code`;
          treat an unrecognized `code` as a generic failure for that item.
