          Returns a list of documents visible to the authenticated organization.
          Documents are typed artifacts: **PRD** (Product Requirements Document
          — describes what to build and why), **IMPLEMENTATION_PLAN**
          (step-by-step technical plan for executing a PRD), **FEATURE** (a
          feature specification), **TEMPLATE** (a reusable document template),
          or **DOC** (an evergreen document). Filter by `type` to fetch only
          plans, by `projectId` to scope to a project, or by `assigneeId` to
          fetch documents assigned to a specific user.
