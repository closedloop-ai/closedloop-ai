          Accepts an API key with `delete` scope, or a signed-in Closedloop
          session. The per-item sibling of the v1 batch delete: the documents
          the caller's organization holds are deleted, and each id that did not
          resolve is reported `artifacts_not_found` rather than counted
          silently. Returns 200 with one result per DISTINCT requested id, in
          the order the caller first named it, even when some items fail. Read
          each item's own `status` and `code`; treat an unrecognized `code` as a
          generic failure for that item.
