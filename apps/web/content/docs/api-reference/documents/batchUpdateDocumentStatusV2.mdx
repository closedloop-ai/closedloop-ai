      - content: >-
          Accepts an API key with `write` scope, or a signed-in Closedloop
          session. The per-item sibling of `POST
          /documents/batch-update-status`, which refuses the whole batch on the
          first missing id, invalid subtype status or stale guard. This commits
          the eligible documents and reports the rest item by item. Returns 200
          with one result per DISTINCT requested id, in the order the caller
          first named it, even when some items fail. Read each item's own
          `status` and `code`; treat an unrecognized `code` as a generic failure
          for that item.
