          Requires an API key with `write` scope. Updates mutable fields on a
          document. All fields are optional — send only the fields you want to
          change. Updating `status` advances the document lifecycle (e.g., DRAFT
          → IN_REVIEW → APPROVED). Changing `assigneeId` sends an assignment
          notification to the new assignee. This endpoint does NOT update the
          document content; to write new content, use the document versions
          endpoint.
