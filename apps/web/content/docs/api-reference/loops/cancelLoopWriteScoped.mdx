      - content: >-
          Cancels a running loop and returns the cancelled loop record.
          Equivalent to `DELETE /loops/{id}` but requires only the `write`
          scope, so clients that create loops with a write-only key can cancel
          their own loops without provisioning the `delete` scope. Stops the
          underlying container (ECS) or dispatches a kill command to the desktop
          compute target, then records a `cancelled` event.
