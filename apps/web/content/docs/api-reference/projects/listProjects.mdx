          Returns all projects belonging to the authenticated organization.
          Projects are the top-level containers for workstreams, documents, and
          repositories. By default, ARCHIVED projects are excluded. Use `status`
          to override — pass `status=ARCHIVED` to see archived projects, or
          `status=IN_PROGRESS,NOT_STARTED` (comma-delimited) to see multiple
          statuses. Use `excludeStatus` to exclude specific statuses. Optionally
          filter by `teamId` to see only projects associated with a particular
          team.
